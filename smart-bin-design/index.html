2026-07-26 ｜ 立项评审稿 ｜ 追踪：米家生态准入、扫地机开放协议、同类竞品动态

①核心链路：七步全自动

人只需要出门时顺手拎走一袋已封口的垃圾，其余环节全部无人值守。

📡
双传感装满检测ToF 激光测高 + 桶底称重，任一达阈值即触发（默认 90% / 3kg），矛盾时以 ToF 为准
🔥
热熔封口打包≤12s，封口宽 ≥8mm，承重 5kg 不漏（成熟 ASAR 方案优化）
💨
腔内喷雾除味本次新增封口后、套袋前的无袋黄金窗口：360° 微雾 + 封口杆自清洁 + 高配 UV-C，根治长期异味
🛍️
风吸自动套新袋负压铺袋 ≤8s，红外确认，失败自动重试 2 次
📤
举升 + 侧推交接本次新增托盘举升 → 前侧滑门开启 → 推板 ≤0.1m/s 送出至交接平台，导向翼板防倒，全程 ≤6s
🤖
召唤扫地机器人IoT 自动召唤 / 小爱语音 / App 按键 / 定时巡检，UWB 对位误差 ±2cm
🛡️
升降护栏围护运送装载确认后护栏升起 15cm 防倾倒，降速 40% 送达指定投放点，到站 App + 语音提醒

垃圾桶与机器人不硬连接，通过米家 IoT 中枢以「事件—场景」联动：兼容用户已有扫地机、跨品牌可扩展、单点故障不拖垮全局。

③两大模块详解

A · 垃圾桶主机
B · 机器人套件
IoT 语音联动

装满检测与自动打包 （默认模式 · 无人值守）

  • ToF 测距（App 可调 70–100%）与称重传感双冗余，任一达阈值即打包；防止单一重物骗过称重
  • 无断点袋盒 + 热熔封口切断，袋盒 25–30 袋（约 1 个月用量）

除味清洁喷雾 —— 解决「长期有味」

  • 时机：封口完成、旧袋推出后、套新袋前（腔内无袋的最佳清洁窗口）
  • 食品级次氯酸/电解水微雾：内壁 360° 喷 3s + 封口机构喷杆自清洁 1s；高配 UV-C 辅照 30s
  • 桶底导流槽 + 可拆接水盘；缺液仅降级提醒，不阻塞流程

推出机构 —— 用「推」不用「抓」

  • 静音丝杆托盘举升 → 前侧自动滑门 → 同步带推板低速推出，两侧导向翼板防倒
  • 纯线性机构 vs 机械臂：成本仅 1/5、故障率低、易做防水
  • 备用电池：停电可完成当前封口动作，避免封一半的袋子卡住

加装套件，而非新机器人

  • 载物平台：磁吸/卡扣固定于扫地机顶部，承重 6kg，防滑硅胶 + 三点限位卡扣
  • 升降护栏环：待机降下收起（照常钻沙发底），装载后升起 15cm 围护；升起期间自动更新机身高度禁区，禁止进入低矮家具底部
  • 红外 + UWB 对接信标；固件 OTA「收运模式」：降速 40%、禁爬 1cm 以上门槛（低重心策略）

四路召唤冗余

IoT 自动召唤小爱语音App / 桶身按键定时巡检

手动打包的强约束设计

用户在 App 将打包模式设为「手动」时，系统强制引导完成米家绑定，未绑定则手动模式不可保存——确保手动 = 可语音 / 远程触发，杜绝「只能按桶身键」的假手动。

官方场景模板

  • 离家模式 → 全屋垃圾桶自动打包收运
  • 每晚 22:00 垃圾量 >60% 自动打包
  • 打包完成 → 玄关灯闪烁，提醒出门带走

④场景冗余设计 ×12

原则：「降级不瘫痪，死机才算失败」。12 类异常全覆盖，任一环掉链子都有 B 计划。

供电与机构类（R1–R2）
打包中途停电 → 备用电池完成当前封口后安全停机；袋子卡住 / 铺袋失败 → 重试 2 次后进入「仅打包不套袋」人工处理态，App + 桶身红灯报警。
耗材类（R3）
清洁液耗尽不阻塞流程：跳过喷雾继续运行并记录，连续干运行 5 次后强提醒。
调度类（R4 / R11）
机器人忙 / 被困 → 任务排队最长 30 分钟 → 改派第二台 → 超时则垃圾袋暂存交接平台、桶照常套新袋继续使用，App 提醒人工取走。多桶同时召唤按「装满程度 + 先叫先得」排队，厨房湿垃圾桶可插队。
安全类（R5 / R6 / R8 / R10）
超重超体积 → 停止推出并回收至桶内，提示人工处理；运送中倾角 / 重量突变 → 立即停车报警；人宠靠近 → 机构动作即停；护栏升起期间 → 禁止进入沙发 / 床底等低矮区域。
环境类（R7 / R9 / R12）
断网走本地网关，纯离线保持「打包 + 套袋」基础闭环、蜂鸣代替机器人运送；湿垃圾渗漏自动触发「袋中袋」双层模式；指定投放点被堵自动切换备用投放点，均不可用则返回交接位等待。
