OUTLOOK 2026–2028

未来推演

竞争已从"谁活下来"变成"以什么物种活下来"。

路径 01 · 上市平台化

智谱 / MiniMax /（阶跃？）

用公开市场资金打持久战。风险：股价与榜单强绑定（智谱单日 -42% 即为例证），持续亏损下的再融资压力。

路径 02 · 技术尖刀化

月之暗面

K 系列能否保持代际压制？C 端订阅 + API 能否覆盖算力成本？大概率 2027 年前后 IPO。风险：算力供给与大厂挖角。

路径 03 · 垂直深水区

百川（医疗）/ 零一（toB）

百川 2027 年 IPO 计划与"AI 医生"闭环；零一要证明"不预训练也能活得好"。风险：天花板与通用模型的能力溢出。

终局判断

2–3 家平台级 + 2–3 家垂直冠军

到 2028 年"六小虎"作为概念将消失。月之暗面握技术势能，智谱握资本与政企纵深，MiniMax 握最健康的收入结构——三足鼎立雏形已现。最大变量：DeepSeek 的阴影、算力、出海兑现、资本市场的耐心。
